## 2. 這條 run 在譜系裡的位置（先講清楚，免得以後誤讀）

h 線目前有四個名字指四組權重：

| 席位 | 是什麼 | 狀態 |
|---|---|---|
| `rl_h1000_20k` | 0k→20k，40 輪 × 500 局 | 已入池、已驗證 |
| `rl_h1000_50k` | multi 的 100 輪版（同一桌上四個學習者） | 已入池 |
| `rl_h1000_30k` | **v3 run 的 round 20**，平衡排程冷啟動的中段快照 | 今日入池（+0.052220／1.477 se vs 20k） |
| `rl_h1000_50k_v2` | v3 run 的 round 60 | **未過判據、未入池**（+0.006430） |
| **`rl_h1000_50k_v4`（本 run）** | **從 30k 出發**的 40 輪 | 本檔的對象 |

→ 本 run **延續過了線的那一支**（30k），不是没过線的那一支（60k）。這與之前每一條
「從 20k 出發」的 run 都不同，是本次裁示的核心。

**使用者報告的外部證據（非本機證據）**：使用者表示在另一台電腦跑過 **15,000 局**
聯賽，兩個中段席位（`rl_h1000_30k`、`rl_i1000_37.5k`）都**強於各自的 20k**。
這件事**無法由本 repo 驗證**（沒有結果檔在這裡），本檔據實標為「使用者報告」。
它與入池裁示一致，也支持本 run 從 30k 出發的選擇。

### 捆綁改動，不可拆因

本 run 相對學習者自己的 0k→20k 那一輪**同時改變多件事**：

1. **起點**：20k → **30k 中段快照**（不是 20k，也不是没過線的 60k）。
2. **池**：七人格、無放回抽 3 → **十席自訂池**（六人格 + 四個凍結網路席），`chess` 被移出（使用者為維持十席的算術而刪）。
3. **排程**：均勻抽樣 → **平衡排程** `--balanced-schedule`。
4. **種子段**：7,200,000–7,219,999 → **7,780,000–7,799,999**（全新段）。
5. **輪數與檔名**：40 輪、輸出 step 由 1 起算 → **在起點 60 之上累加**，最終檔名 `step_000100.pt`。

> **這五項是一包，結果只能歸因到整包。** 任何「是因為 X 才變好／變差」的說話都不
> 成立。要拆，只能各自單開對照 run，那是新的決定，由使用者下。


## 8. Adam 冷啟動風險與 guardrail 觀察重點

### 8-1 冷啟動是什麼（事實）

`--init` 路徑只載入**權重**（`rl.rl_train._start_net` → `rl.policy.load_policy`），blob 為空：**Adam 狀態不還原、`entropy_reference` 不沿用起點檔的 1.9924735672333662**（該值存在檔內，冷啟動路徑不讀）。優化器由 `_make_optimizer` 全新建立，動量一階／二階皆為零。起點檔內其實存有 Adam 狀態，但本 run **不用它**。

（起點檔的 `entropy_reference` 是它自己那條 run 第 1 輪的量測值；本 run 的 reference 由本 run 第 1 輪在新池下重新量。）

### 8-2 風險（機制推測，標明為推測）

動量為零時，Adam 最初數步的更新量接近 `lr × sign(g)`（有效步長偏大），常見行為是前幾輪 policy_loss / value_loss 出現一次性震盪後回落。**這是機制常識，不是對本 run 的預測。** 若前幾輪就觸發 guardrail，照 §8-3 處理，不調參。

### 8-3 guardrail（沿 plan10 §6，跑後不改）

| guardrail | 條件 | 本 run |
|---|---|---|
| `nan_or_inf` | 統計欄位非有限值 | 觸發即停 |
| `kl_anchor` | `kl > 0.05` | `kl_coef = 0` → **永不觸發** |
| `entropy` | `ent < 0.5 × entropy_reference` | reference = **本 run 第 1 輪**實測值（§8-1） |
| `first_ratio_dev` | `> 1e-6` | 觸發即停 |
| `disk` | free < 5.0 GB | 唯一可續跑的例外（開訓前實測 1.1T free） |

- **`entropy_reference` 來自新環境**：本 run 第 1 輪、10 席池、平衡排程下量到的 entropy。閾值 = 0.5 × 該值。它同樣是「第 1 輪單點」，穩定性有限，記錄在此。
- **觀察重點**：
  1. **前 5 輪**：`policy_loss`、`value_loss`、`clip_fraction`、`explained_variance` 是否出現冷啟動震盪；`entropy` 對 reference 的比值。
  2. **全程**：`learner_reward_mean` / `learner_rank_mean` 趨勢（曲線，不入判準）、guardrail 值每輪記錄於 `rounds.jsonl`。
  3. 觸發任一非 `disk` 者：該輪已存檔、exit 1，訓練視為**未完成**——不評測、不入池、不續跑、不調閾值、不開第二條；結果照記為「第 k 輪被 `<name>` 中止」，附 entropy 軌跡，停下等裁示。
- 中途不得因 entropy 下滑手動介入；不設「達到 20,000 局前自動停止」以外的停止條件。
