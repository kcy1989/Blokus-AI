### 捆綁改動，不可拆因

本 run 相對「v4 的 round 35」同時改變多件事：

1. **起點**：v4 run 的 round 35（一個未入池的中段檢查點）。
2. **池**：12 席（使用者指定的字面序），含起點的**父代** `rl_h1000_30k` 與**祖父代** `rl_h1000_20k`，但**不含**學習者當前權重。
3. **排程**：均勻抽樣 → **平衡排程** `--balanced-schedule`。
4. **種子段**：7,806,999 以上全部未註冊區 → **7,830,000–7,882,499**（全新段）。
5. **輪數與檔名**：105 輪、輸出 step 由 1 起算 → **在起點 95 之上累加**，最終檔名 `step_000200.pt`。
6. **迴圈內評測池**（2026-10-15 裁示）：預設七人格 → **§5 的 11 席池**（`--eval-pool`）。**只影響訓練曲線，不影響 §5 判準**；程式預設值不變（不帶旗標時逐位是舊行為，有測試釘住）。

| 項 | 值 |
|---|---|

| `paired_diff` | `mean(reward_current − reward_start)`（逐 seed） |

### 通過條件

```
paired_diff > 0   且   paired_diff ≥ 1.3 × paired_se
```

- **單側假陽性率約 9.7%**（P(Z > 1.3)，標準常態）。
- 1000 局 SE 約 0.037–0.044（本專案多次實測）→ 門檻約 **+0.048 ~ +0.057**。
- **直接決策**：跑完這一次 1000 局配對評測即可直接判斷是否入池，**不再做第二次複驗或任何其他評測**。停下等使用者確認入池。
- **一條候選**。不入池、不開第二條；重做是新決定，由使用者下，並註明是在看過結果後做的。
- **通過僅屬「弱證據」**，報告不得寫「已證明更強」。只比起點 `step_000035.pt`，不與 `rl_h1000_20k`、`rl_h1000_30k`、`rl_h1000_50k`、未入池的 v2/v4 或任何其他版本比。
- 過線只是取得入池資格；與既有席位並存或取代，由使用者屆時裁示，本檔不預設。

### 這個判準的已知偏性（預先寫死，跑後不改）

1. **評測池 ⊆ 訓練池**：訓練池 12 席全部……評測池 11 席裏的 `wolf, chess, fox, hunter, optimizer, builder, intruder, rl_b1000_50k, rl_i1000_37.5k, rl_o1000_50k_v3, rl_h1000_30k` **全部落在訓練池內**（訓練池只多 `rl_h1000_20k`）。也就是說判據主要在「它訓練時打過的對手」上打分。plan10 §8 風險 2（對凍結池過適、偵測受限）對本 run 從例外變成**主要情形**。**通過時的措辭必須是**「在這個 11 席分布上優於起點」，**不得**寫成「普遍變強」。
2. **評測池含起點的父代 `rl_h1000_30k`**：一部分比賽是「候選 vs 起點的父代」，所以判据部分地在度量「比父親強多少」而不是「比父親的兒子強多少」——注意起點自己就是從 30k 训出來的，這個對手的相對強度對候選有利。
3. **有放回抽樣**：11 席自訂池每局抽 3 名對手、可重複。預期重複率約
   1 − (11·10·9)/11³ ≈ **18.2%**；實測值記入 §14。訓練時的平衡排程仍是三名互異（構造保證），兩者不同，不是 bug。

## 8. Adam 冷啟動風險與 guardrail 觀察重點

### 8-1 冷啟動是什麼（事實）

`--init` 路徑只載入**權重**（`rl.rl_train._start_net` → `rl.policy.load_policy`），blob 為空：**Adam 狀態不還原、`entropy_reference` 不沿用起點檔內的 1.9362780627082377**（該值存在檔內，冷啟動路徑不讀）。優化器由 `_make_optimizer` 全新建立，動量一階／二階皆為零。起點檔內其實存有 optimizer 狀態，但本 run **不用它**。

（起點檔的 `entropy_reference` 是 v4 run 第 1 輪在自己的池下量的；本 run 的 reference 由本 run 第 1 輪在 12 席池下重新量。）

### 8-2 風險（機制推測，標明為推測）

動量為零時，Adam 最初數步的更新量接近 `lr × sign(g)`（有效步長偏大），常見行為是前幾輪 policy_loss / value_loss 出現一次性震盪後回落。**這是機制常識，不是對本 run 的預測。** 若前幾輪就觸發 guardrail，照 §8-3 處理，不調參。

### 8-3 guardrail（沿 plan10 §6，跑後不改）

| guardrail | 條件 | 本 run |
|---|---|---|
| `nan_or_inf` | 統計欄位非有限值 | 觸發即停 |
| `kl_anchor` | `kl > 0.05` | `kl_coef = 0` → **永不觸發** |
| `entropy` | `ent < 0.5 × entropy_reference` | reference = **本 run 第 1 輪**實測值（§8-1） |
| `first_ratio_dev` | `> 1e-6` | 觸發即停 |
| `disk` | free < 5.0 GB | 唯一可續跑的例外（開訓前實測 1,100.2 GB free） |

- **觀察重點**：
  1. **前 5 輪**：`policy_loss`、`value_loss`、`clip_fraction`、`explained_variance`、`approx_kl_old` 是否出現冷啟動震盪；`entropy` 對 reference 的比值。
  2. **全程**：`learner_reward_mean` / `learner_rank_mean` 趨勢（曲線，不入判準）、guardrail 值每輪記錄於 `rounds.jsonl`。
  3. 觸發任一非 `disk` 者：該輪已存檔、exit 1，訓練視為**未完成**——不評測、不入池、不續跑、不調閾值、不開第二條；結果照記為「第 k 輪被 `<name>` 中止」，附 entropy 軌跡，停下等裁示。
- 中途不得因 entropy 下滑手動介入；不設「達到 52,500 局前自動停止」以外的停止條件。

3. 因此本診斷在**同一個 1000 局 12 席訓練池平衡排程 specs** 上，對起點 `v4 r35` 與終點 `h100k`（`step_000200.pt`）同時跑 **`argmax`** 與 **`softmax` ($T=1.0$)**（共 4 次 `play_batch`），直接拆開：

   - 切到 `argmax` 後，在同一個 12 席平衡分布下配對差是多少（對照 11 席有放回驗收池的 `+0.008050`）；
   - 同一 checkpoint 從 `softmax` 切到 `argmax` 的絕對分差（量化決策模式不對稱）。

#### 15-3-3 診斷拆解結論

1. **不是「12 席訓練池 vs 11 席評測池」或「平衡排程 vs 有放回抽樣」造成的落差**：
   在同一份 12 席訓練池平衡排程 specs 上，`argmax` 的配對差是 **−0.090160（−2.263 se）**，比 11 席驗收池的 **+0.008050** 更負；第 12 席 `rl_h1000_20k` 在 `argmax` 下也是負差（**−0.0476**）。換回訓練池並未讓 `argmax` 變好。
2. **PPO 確實在它直接優化的目標（`softmax, T=1.0`）上大幅進步了**：
   同一份 1000 局 specs 在 `softmax` 下，`h100k` 對起點 `v4 r35` 的配對差為 **+0.183630（+3.975 se）**，名次由 2.414 升至 2.243、餘格由 14.470 降至 13.207，且 **12 個對手席位在 `softmax` 下全數為正**（含 `rl_h1000_20k` **+0.2259**、`rl_h1000_30k` **+0.1938**）。這也印證 `rounds.jsonl` 從 2.48 升到 ~2.60 是真實的策略分布改善，不是種子偏移。
3. **全部落差來自 `softmax (T=1.0)` 訓練目標與 `argmax` 評估模式的脫鉤（plan10 §8 風險 4 的直接定量證據）**：
   - 起點 `v4 r35` 從 `softmax` 切到 `argmax` 會跳升 **+0.7263**（2.4413 → 3.1676）；
   - 經過 105 輪訓練後，終點 `h100k` 的 `softmax` 底線墊高了 **+0.1836**（壓低次優分支的機率），但切到 `argmax` 的跳升幅度縮減為 **+0.4525**（2.6249 → 3.0775），最高機率的那個點（top-1 mode）反而比 `v4 r35` 退了 **−0.0902**。
4. **處置不變**：本節為純診斷，**不入池、不改判準、不作為通過依據**；種子段 `stage RL h100k eval2`（7,888,000–7,888,999）已用畢，日後不得再取用。
