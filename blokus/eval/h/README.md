# h — hunter 血統

學習者風格 h（hunter）。所有 run 都是單一學習者、其餘對手凍結，並使用
`--balanced-schedule`。目前最強且已入池的 h 權重是 `rl_h1000_50k`（四學習者同桌的
milestone 1）；單打線最新的入池者是 `rl_h1000_100k`（使用者裁示）。

## 分支圖

```
rl_h1000_20k  (shared/0k-to-20k)
├── v2 run (data/rl/h/50k_v3)
│   ├── round 20  → rl_h1000_30k        入池（本目錄 v2/ §17–§18）
│   └── round 60  → rl_h1000_50k_v2     未入池（+0.006430，未過閾值）
└── v4 run (data/rl/h/50k_v4)，起點 rl_h1000_30k step 60
    ├── round 35  → 非席位（+0.046100，未過 1.3 se）
    │   ├── t05 run (T=0.5)            未入池
    │   └── 100k run → rl_h1000_100k    入池（裁示；+0.008050）
    └── round 40  → rl_h1000_50k_v4     未入池
```

`rl_h1000_50k` 不在這條單打樹上：它來自四學習者同桌，證據在
[`shared/four-at-once/`](../shared/four-at-once/README.md)。
