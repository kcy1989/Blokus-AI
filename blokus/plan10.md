## 2. 目標

同時訓練四個學習者(h、o、b、i),從各自的 20k 權重繼續,比較「對固定池」與「對動態同伴」兩種環境下的變化。累計訓練目標 50k、100k、150k 局。**不自動停止**,是否繼續由人工分析後決定。

## 3. 規格

| 項目 | 規格 |
|---|---|
| 起點 | 各自的 20k 權重繼續訓練 |
| 每步局數 | 500 |
| 同場局 | 360 局:四學習者同桌,24 種座位排列 × 15 輪,**每輪種子不同** |
| 固定池局 | 140 局:有放回抽 3 個對手;每局由四個學習者輪流坐**同一個位置**,同種子成對,共 560 條學習者軌跡 |
| 固定池 | 7 人格 + 4 個凍結 20k(共 11) |
| 排名 | 平手共享較好的名次(並列第 1 → 兩者皆 1,下一位為 3),沿用既有規則,不改動 |
| 單局獎勵 | `r = (5 − 排名) − 餘格/100` |
| 兩種局合併 | 兩種局各算平均獎勵,相加後除以 2(1:1,不按局數加權) |
| 存檔 | 每 10k 局(= 每 20 步) |
| 里程碑 | 50k、100k、150k 局(= 第 100、200、300 步) |
| 對手 | 不留對手(不保存學習者過往快照) |
| 記錄 | 兩條曲線分開:對固定池、對動態同伴 |
| 目錄 | `eval/rl-multiple-train/` |

每步學習者軌跡:同場局 360 × 4 = 1440,固定池局 140 × 4 = 560,合計 2000。

## 5. 已知風險(非待決)

1. **動態同伴曲線不可跨時間比較**:對手隨訓練改變,環境非平穩。該曲線上升不代表變強。進步的證據只能來自固定池曲線。
2. **固定池含學習者自己的凍結 20k**:學習者可能抽中自己的起點。固定池曲線是「對一組固定對手的表現」,不是純粹的對外實力,報告須標明。
3. **平手共享較好名次**:同桌獎勵總和不再固定。同場局的學習者之間並非嚴格零和,梯度分析時不能假設零和。
4. **獎勵尺度**:`5−排名` 範圍 1–4,餘格項最多約 0.3。排名項佔主導。
5. **事後選擇**:不自動停止、人工看曲線決定,選擇點會偏向有利結果。分析時應固定指標與種子集,並把選擇點的決定寫在查看之前。
6. **同場局樣本不獨立**:四條軌跡來自同一局,統計時以局為單位,不以軌跡為單位。
